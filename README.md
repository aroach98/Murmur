<h1 align="center">Murmur</h1>

<p align="center"><em>Hold a hotkey anywhere in Windows, speak, release — your words are typed into whatever has focus.</em></p>

Murmur is a local, offline dictation utility. Audio is captured to memory, transcribed
on your CPU by [whisper.cpp](https://github.com/ggerganov/whisper.cpp) (via
[Whisper.net](https://github.com/sandrohanea/whisper.net)), and never written to disk
or sent anywhere. The only network access in the entire app is the one-time speech
model download on first run.

## Quick start (no build needed)

1. Clone or download this repo.
2. Run **`publish\Murmur.exe`** — it's fully self-contained; no .NET install required.
3. On first run, the Settings window opens: click **Download model** (the default
   `base` model is a 142 MB one-time download), then Save.
4. Click into any text field anywhere, **hold F9, speak, release**. About a second
   later your words appear at the cursor.

A violet Murmur icon sits in your system tray; a "● Recording…" pill shows at the
bottom of the screen while the hotkey is held.

To start with Windows: put a shortcut to `Murmur.exe` in `shell:startup`.

## How it works

- A global low-level keyboard hook watches the hotkey (default **F9**) — hold to
  record, release to transcribe. The hotkey is swallowed while Murmur runs; all
  other keys are untouched.
- The mic records 16 kHz mono into memory (recordings capped at 120 s; quiet mics
  are gain-normalized automatically).
- Text lands via `SendInput` + `KEYEVENTF_UNICODE` synthetic keystrokes — works
  across native, UWP, browser, and Electron apps with no per-app integration.
  Apps that mangle rapid synthetic keystrokes (Windows Terminal, legacy consoles,
  Windows 11 Notepad) automatically get clipboard-paste instead, with your
  existing clipboard preserved and restored. The list is `PasteWindowClasses` in
  `TextInjector.cs`; the Settings dialog can also force paste mode globally.

## Changing the hotkey

Right-click the tray icon → **Settings…** → click the hotkey box → press a key →
Save. Single non-modifier keys only (F-keys, CapsLock, Pause, …); plain letters are
rejected because the hotkey is swallowed system-wide. Applies immediately.

Or edit `%APPDATA%\Murmur\settings.json` (`HotkeyVk` is a Windows virtual-key code,
e.g. `120` = F9) and restart.

## Swapping the whisper model

Settings → pick a size → **Download model** → Save.

| Model  | Download | Speed vs accuracy                          |
|--------|----------|--------------------------------------------|
| tiny   | 75 MB    | fastest, rough                              |
| base   | 142 MB   | **default** — good accuracy, ~1 s latency   |
| small  | 466 MB   | better on hard audio, slower                |
| medium | 1.5 GB   | best, several seconds per utterance on CPU  |

English-only (`.en`) ggml models, fetched from the whisper.cpp repo into
`%APPDATA%\Murmur\models\`. Already have a model file? Drop it at
`%APPDATA%\Murmur\models\ggml-<size>.en.bin`.

## Building from source

Requires the .NET 8 SDK:

```
dotnet publish -c Release -r win-x64 --self-contained true -o publish
```

Note: the whisper native library is loaded by runtime path-probing, so keep the
publish folder intact — single-file publish is not supported by Whisper.net's loader.
The icons are generated by `Assets\gen-icons.ps1`.

## Behavior details & limits

- Taps under ~250 ms are ignored (accidental hotkey press).
- Silence / non-speech produces nothing; a tray balloon tells you if the mic
  recorded pure silence (wrong default device or privacy permissions).
- Injection targets whatever has focus **when transcription finishes** — don't
  switch windows during the ~1 s transcribe step.
- Apps running as Administrator won't accept input from a non-elevated Murmur;
  run Murmur elevated to dictate into elevated apps.
- Each dictation appends a line to `%APPDATA%\Murmur\Murmur.log` and keeps the
  last recording at `%APPDATA%\Murmur\last-recording.wav` (local only) for
  troubleshooting.

## Headless test modes (CLI)

```
Murmur --transcribe file.wav [--model base] [--out result.txt] [--raw]
Murmur --inject "text to type" [--delay 1500] [--paste] [--require-title <substr>]
Murmur --select-copy [--delay 1500] [--require-title <substr>]
Murmur --combo ctrl+shift+w [--delay 1500] [--require-title <substr>]
Murmur --focus <title substring>
Murmur --list-mics [--out file]
```

`--require-title` refuses to send keystrokes (exit 3) unless the foreground window
title contains the substring — checked continuously during injection, so scripted
tests can never type into the wrong window. `test\run-when-idle.ps1` uses these to
run Notepad/VS Code round-trip injection tests once the desktop is idle.

## Source layout

| File | Role |
|---|---|
| `Program.cs` | entry point, single-instance mutex, CLI test modes |
| `TrayApplicationContext.cs` | tray icon, pipeline wiring, lifetime/cleanup |
| `KeyboardHook.cs` | WH_KEYBOARD_LL global hook, hold/release detection |
| `AudioRecorder.cs` | NAudio mic capture → 16 kHz mono float samples |
| `Transcriber.cs` | Whisper.net wrapper, gain normalization, noise filtering |
| `TextInjector.cs` | SendInput unicode typing, clipboard-paste fallback, focus gate |
| `WindowFocuser.cs` | test-harness foreground control (AttachThreadInput) |
| `RecordingOverlay.cs` | no-activate topmost recording/transcribing indicator |
| `SettingsForm.cs` / `Settings.cs` | hotkey capture, model picker/downloader, JSON persistence |
| `ModelManager.cs` | model paths + one-time downloads |
